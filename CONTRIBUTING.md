# Contributing to InstaStatus-Analyzer

We love your input! Please read these guidelines before submitting a PR.

## Development Setup

1. Fork the repo
2. Clone your fork
3. Create a virtual environment: `python -m venv .venv`
4. Activate it: `source .venv/bin/activate`
5. Install dev dependencies: `python -m pip install -r requirements-dev.txt`
6. Run tests: `python -m pytest`

## Coding Style
- Follow PEP 8.
- Use type hints where possible.
- Add docstrings to all public functions.

## Testing
- Write unit tests for new features in `tests/`.
- Ensure `pytest` passes before committing.

## Pull Request Process
- Open an issue describing your change first.
- Keep PRs focused and small.
- Update documentation if needed.

Thank you!
